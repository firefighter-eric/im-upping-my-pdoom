# 视觉设计与评审

## 学习原片的方法

全片缩略图用于识别章节、密度、明暗和母题；挑选开场、主歌、副歌、桥段、结尾以及失败镜头，查看连续片段和音轨。记录“时间 → 所唱内容 → 主体 → 动作 → 镜头 → 转场 → 所服务的意义”。选定同一时刻比较原片与候选，避免各自挑最好看的帧。

区分画面观察、作者文档意图和实际听辨结论。声明采样范围；未逐句播放审查就不能宣称全部歌词或所有拍点已准确覆盖。参考用于新歌时，优先继承形变、层级、节奏和隐喻构造方法。

## 歌词成为画面的四个层次

1. **覆盖**：完整、可读地呈现唱出的每句歌词，长句合理分块；伴唱与重叠声部可用独立层级。
2. **节奏**：用词级起点控制出现或强调，句尾留出阅读时间。预显可以帮助阅读，但强调不提前冒充已唱。
3. **语义**：关键词引发明确事件，例如下降变成坠落、转向改变路径、堆叠改变结构；避免所有词只做同一种缩放。
4. **空间**：文字可沿曲线、被机器打出、刻在物体上、进入旋涡或被盖章；变形期间仍需保证读完。实在不可读时保留一个清晰的歌词层。

建立覆盖账本：逐句 ID、原文、演唱区间、显示区间、场景 ID、呈现方式、人工检查状态。词级 JSON 存在不等于文字真的被画出；每一遍副歌也要记录。器乐段不用虚构歌词，可发展母题或留白。

## 视觉语言与镜头

- 每个章节选定主体、空间关系和视觉机制：图表、实体、纸张、机器、粒子等都可用，但主题由歌词决定。
- 建立有限的字体角色与调色板；大字承担歌词，中字承担语义重点，小字提供氛围。微小 HUD 不能承担必读信息。
- 场景可有不同材料和构图，以字体、色彩、母题和运动方式保持整体一致。
- 用停顿、加速、骤停和有意的动静交替制造节奏。速度和冲击发生在有意义的位置，持续漂浮和持续抖动容易消耗注意力。
- 让转场有因果：同一条线变成路径、同一个圆变成洞、镜头跟随某个物体进入下一场景。切镜和留白也可成立，不必每次形变。
- 同时安排远近、大字与细节、亮与暗、拥挤与留白。副歌重复应有变化，结尾回应前面的母题。
- 检查正常播放速度的可读性、目标观看设备和安全边距。4K 单帧放大可读不代表正常观看能读。

## AGI／pdoom 案例：机制与局限

2026-10-02 对本地原片的代表帧和连续序列审看发现：

| 原片时间约 | 值得学习的机制 |
| --- | --- |
| 10–13 秒 | loss 曲线下降后，镜头进入等高线地形；抽象数据成为空间 |
| 22–24 秒 | 输入框、明亮过渡、巨型文字与橙色概率数字交替；尺度和明暗形成冲击 |
| 33–38 秒 | 眼睛、面具和标注围绕同一隐喻发展 |
| 44–48 秒 | 文字绕奇点旋转并进入扭曲网格；排版成为空间的一部分 |
| 约 82 秒 | “转向”在画面中成为方向改变的事件 |
| 约 99 秒 | 回形针重复把抽象威胁变成具体对象 |
| 103–105 秒 | 燃烧引线、歌词和镜头推进连接到后续图形 |

整体强项是动态图形、技术隐喻、动态字体和克制的黑／骨白／橙色层级，带有冷峻、干燥幽默和危险感。局限包括小字、强闪光与快速镜头带来的阅读压力，以及旋涡、线场的反复；其语义也依赖观众理解 AI 语境。上表是采样观察，不是全片逐词同步证明；“逐句可读并按词同步”也有上游 treatment 的明确设计依据。

本地 AGI v001 的三个候选说明了常见失败：抽象版反复使用中心粒子球和通道，叙事版角色动作变化不足，歌词版主要是固定字幕模板。装饰柱状条乘以整体音量不是真正的多频段频谱。应优先修正画面结构、视觉事件和排版，技术升级本身不会解决这些问题。

这是本歌案例，不把黑橙色、技术图表、旋涡或 AI 意象固定到其他歌曲。

## 审看结论的写法

指出具体时间、可见问题、观众受到的影响和建议改法。例如“副歌两遍使用相同中心构图，第二遍增加空间深度并让母题发生一次不可逆变化”。区分技术通过、歌词通过、视觉待改，不用一个总分掩盖问题。
