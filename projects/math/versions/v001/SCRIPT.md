# 目录滚动脚本 v001

没有解说、字幕或额外视觉段落。全片画面为固定路径栏与滚动论文目录。

最终时长 T 等于用户选定的完整音轨时长；当前实时画面演示 T=180 秒，尚未绑定为完整成片时长。

| 时间 | 画面 |
| --- | --- |
| 0–2 秒 | 停在首行，让观众认出 math / preprints 路径与论文列表。 |
| 2–3.5 秒 | 用 1.5 秒平滑加速进入连续上滚。 |
| 3.5–T−3.5 秒 | 匀速滚过全部 722 个目录，路径栏保持固定。 |
| T−3.5–T−2 秒 | 平滑减速，末行完整进入画面。 |
| T−2–T 秒 | 停在末行，保留完整音乐结尾。 |
