# OpenAI Math · 论文目录滚动 v001

用户要求最简单的屏幕滚动加音乐，选择 GitHub `preprints/` 论文列表，并提供白底目录截图作为版式参考。本作品独立登记为 `MATH_001 / math`。

## 画面

保持截图的白底、蓝色文件夹图标、目录横线和 `Initial commit` 列。顶部固定 `math / preprints /`，下方列表从首行平滑滚到末行。没有旁白、额外解说、闪切或标题包装。

列表来源固定为 `openai/math` 提交 `adc7f1241b42e322a6451854ab7e4b4c146bf78a` 的公开目录快照，共 722 个目录，原始 API 响应和用户截图保持原样并登记 SHA-256。该提交没有父提交，提交说明为 `Initial commit`。显示名称来自原始目录；超出列宽的名称使用省略号，完整名称保留在绑定 JSON 中。

画面为根据用户截图与实际目录数据进行的代码绘制，不标为浏览器原始录像。TypeScript + Three.js/WebGL 使用按时间确定的滚动位置；文本保持真实，不生成或概括论文结论。

## 配乐与时长

用户选择使用自己指定或提供的音乐，并正在考虑“误闯天家”。具体曲目版本、音频文件与权利为 TBD，目前不下载或混用其他作品的音轨。

当前提供无配乐的实时画面演示，暂按 180 秒遍历全部目录，可播放、暂停和拖动。180 秒只是画面演示参数；manifest 的最终时长与帧数仍为空。配乐确定后，以实际完整音轨时长设置最终滚动速度和 `ceil(duration × fps)` 帧数。

离线 Preview 计划 1920×1080、30fps、固定四次时间采样；正式成片计划原生 3840×2160、60fps。最终输出规格以绑定 manifest 为准。

## 阶段与验收

版本保持 draft，阶段为 visual-draft-awaiting-music，未登记完整视频或人类批准。完整带音乐导出、音频包一致性、全片解码、实际成片播放和审核将在输入确定后进行。实时画面与静帧仅供检查目录、滚动和版式。
