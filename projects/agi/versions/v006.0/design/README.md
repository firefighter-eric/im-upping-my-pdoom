## 右栏如何滑动

推荐采用“上一条淡出、当前条停住、下一条露头”的切卡方式。不要连续匀速滚动整篇文章。切换的候选参数为 0.35–0.5 秒上滑，缓出；当前标题和左侧关键词共用橙色。正文随整张卡移动，不逐字打字。阅读期间停止背景装饰运动。

卡片结构：**梗名 → 一句话解释 → 这句歌词怎样用这个梗 → 简短出处**。复杂概念可用一个小图解替换正文。来源用小字，必读解释不能用微小字。

阅读时长需要在后续有声样片里验证，静图只能判断空间。先以每张 5–8 秒作为工作假设：只有约 2 秒的歌词不能塞入 C 图这样的长解释。密集段优先 15–25 字的短释义，将同一概念跨相邻歌词保留；仍放不下时另行设计延伸讲解段，不能为了“所有梗”而暗中变速、裁剪原片或强行高速滚屏。完整覆盖账本、是否加入口播／延伸段属于后续制作决策，本次没有执行。

原音轨与原视频按同一时间零点连续播放；注释可以适度预显，但引用的歌词和解释对象必须匹配。进度条由真实媒体时钟计算；AI 样图中的进度长度不是时间验收结果。

## 本轮示例文案及证据

P(doom)：对 AI 导致生存级灾难的概率估计；不同人对“doom”的具体定义有差异。中文歌词“我又调高了末日概率。”为本次意译。它将能力增长带来的担忧写进反复的副歌，是本提案对歌词的解读，不声称作者公开确认该意图。[术语讨论：Taboo P(doom)，2023-02-03](https://www.lesswrong.com/posts/omDu7vNy3YyKXsvCd/taboo-p-doom)。

回形针最大化：Nick Bostrom 2003 年文中讨论过只以制造回形针为目标的超级智能，及其把地球与太空资源改成制造设施的后果。样图总结“目标错了，越高效越危险”是编辑性概括，图中箭头是思想实验的条件性示意，不是声称所有单一目标必然造成灾难。[Bostrom 原文 §2 与 §4](https://nickbostrom.com/papers/ethical-issues-in-advanced-ai/)。

样图上露出的 ChatGPT、FOOM、Killswitch 只演示前后注释的位置。B 图自动添加的“人类最后的对话伙伴？”属于未采纳的生成文案，不作为梗事实。全片其余指涉（例如 CDR、Loom、shinigami eyes）尚未在本轮逐条考证，不能把歌词推测写成确定来源。不要提前编造梗总数。
