# AGI · 参考引擎路线 · v002

- 用户要求：采用 mexicat/pdoom-video 的 TypeScript＋Three.js／WebGL 技术路线，全面参考其他制作技术；画面为原生 4K、60fps，人声分离、歌词强制对齐和节拍分析为核心步骤。
- 本版本从 v001 分支，状态 draft；目前只完成技术迁移与音频数据准备，没有完整新成片或人工批准。
- 创意处理：使用参考项目的 22 段场景、歌词／节拍时间线、几何和 shader、排版及后期引擎作技术基线。原创创意改写范围为 TBD，不把这些参考场景宣称为本次原创。
- 来源代码固定到 bdbad537a7b7af3213475651774030c47568c181；MIT 版权声明、字体与来源说明保留。参考项目的回放缩略图已随引擎迁入，属于参考资料，其独立使用权状态为 TBD。
- 输出：3840×2160、CFR 60fps、9400 帧；完整原 AAC 音轨 156.650667 秒，不改速、不截短、不重编码。
- 画面：逻辑设计空间 1920×1080、物理倍率 2，各图层、字体与 shader 在真实 4K 画布出帧；使用辉光、光晕、色差、颗粒、暗角等参考后期。
- 运动模糊：自适应 4／12／36／108／324 次子帧采样，快门为帧间隔的 0.2，误差阈值 3／255；静帧与短视频用于技术验收。
- 导出：Chrome WebGL → 异步 GPU 读回 RGBA → WebSocket（最多两帧未确认）→ ffmpeg H.264 CRF 18、yuv420p；垂直翻转恢复 GPU 读回方向。保留 JPEG base64 的 renderFrame 接口以兼容静帧与其他版本。
- 音频：精确校验原 WAV；Demucs htdemucs_ft 输出人声／鼓／贝斯／其他，mel-band-roformer karaoke 进一步分离主唱。当前 WAV 时间零点不套用参考 MP3 的 -23ms 编码延迟。
- 对齐：MMS_FA 与 wav2vec2 LV60K 模型分别处理人声单声道、左右声道和主唱，CTC 全局 Viterbi 强制对齐；辅以音素拼写、人声音高／RMS／起音信号，以及 MLX Whisper large-v3-turbo 的独立时间戳交叉检查。
- 节拍：从分轨重新拟合固定节拍网格、鼓起音、重拍与 100Hz 分轨包络；歌曲小节／段落计划继承参考解释，仍需人工审看。
- 不继承来源项目的人工逐词修正或人工批准。当前对齐生成 46 行；低置信度词与 QA 图保留，用于听辨审核。
- 模型命名按参考算法兼容性固定，实际软件版本、输入／工具／数据哈希和各步结果见 runs/AUDIO_*.json；模型权重与中间音频放在忽略的 .cache 中。
