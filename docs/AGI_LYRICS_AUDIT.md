# AGI 歌词文字校对

2026-10-03，对照歌曲创作者 osmarks 发布的标准歌词，核对 AGI 已登记的六个制作版本。本次登记文字对照结果，不修改历史制作版本或成片，不授予媒体人工批准。

## 来源

- 文字校对依据：[osmarks 的标准歌词](https://docs.osmarks.net/hypha/p%28doom%29_song_objectively_correct_interpretation)。页面提供完整歌词和逐句解释；取首个预格式化歌词块，去除段落标题与用于排版的反引号，保留正文大小写、标点和撇号。
- MV 制作仓库：[mexicat/pdoom-video 的歌词源文件](https://github.com/mexicat/pdoom-video/blob/a048746d25fa0333ca884fb79fe4482b9c89250d/lyrics/lyrics.src.js)，其中句级时间为粗略标注；[逐词时间数据](https://github.com/mexicat/pdoom-video/blob/a048746d25fa0333ca884fb79fe4482b9c89250d/data/lyrics.json)另含置信度与额外声部记录。
- 机器可核对记录：[lyric-text-audit_v001.json](../projects/agi/sources/analysis/lyric-text-audit_v001.json)。包含访问时间、来源与提取结果哈希、固定 Git 提交、各版 manifest／歌词数据哈希及逐字符差异。记录以稳定 ID 登记在作品 project.yaml 中。

## 画面与同步的审核边界

- v003.0 的历史 QA 记录过章节标题与副歌文字重叠；v003.1 记录了修正。证据分别见 [首版 QA](../projects/agi/versions/v003.0/runs/QA_2026-10-02T12-29-43-241Z.json) 和 [修订 QA](../projects/agi/versions/v003.1/runs/QA_2026-10-02T12-35-45-391Z.json)。
- 当前 v005.0 仍有 13 个自动对齐置信度低于 0.6 的词及 4 处额外声部待听辨。低置信度主要描述时间对齐依据，不能直接解释为 13 个错词；文字与来源一致也不能证明演唱时间、高亮或显示时间完全正确。
- 正常速度的有声同步、伴唱／重复发声、全文阅读时间和主观视觉质量仍待审核，见 [v005.0 QA](../projects/agi/versions/v005.0/QA.md)。本次没有重新转录、对齐、渲染或逐帧验收。

后续需要统一文字或调整字幕时，按版本规则创建新制作版本，以作者文本作文字依据，再核对实际演唱；伴唱和生成音轨的变体单独登记。原音轨保持完整，旧版代码、数据、成片与绑定的执行证据保持可追溯。
